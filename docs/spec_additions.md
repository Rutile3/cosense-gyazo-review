# 追加仕様

## 2026-09-27 Cosense Gyazo 配信再開チェッカー

- Cosenseの通常のプロジェクトエクスポートJSONを、ドラッグ＆ドロップまたはファイル選択でブラウザ内に読み込めるようにした。
- `pages[].lines[].text` 内の `gyazo.com` および `i.gyazo.com` のURLを抽出し、32桁の画像ID単位で重複を除去するようにした。
- 同一画像の全掲載元ページと該当行を保持し、Cosenseページへのリンクを表示するようにした。
- 画像の状況を「未確認」「完了」「保留」「対象外」で管理し、プロジェクト名別に画像IDと状況だけをローカルストレージへ保存するようにした。
- 状況絞り込み、画像ID・ページ名・該当行の検索、次の未確認画像を1件ずつ開く機能を追加した。
- 画像ID、確認用URL、状況、掲載元ページをUTF-8 BOM付きCSVで出力できるようにした。
- JSONの構文・形式・抽出結果に問題がある場合、日本語のエラーメッセージを表示するようにした。
- Gyazo上の配信再開はユーザーが手動で行い、ツール上の完了は自己申告である旨を画面とREADMEに明記した。
- 架空データのみを含む動作確認用JSONを追加した。
- 32桁を超える16進文字列を画像IDの先頭32桁として誤抽出しないようにした。
- 実エクスポートに存在する、`lines[]` が文字列だけの簡略形式にも対応した。
- Bootstrap CDNを読み込めない場合も主要操作を利用できる最低限の代替スタイルを用意した。

## 2026-09-27 Gyazo画像の表示テスト

- `i.gyazo.com` のPNG画像を `Image` オブジェクトで読み込み、「表示できた」「表示できない」「時間切れ」を判定する機能を追加した。
- 個別の表示テストと再テストに加え、現在のページ・絞り込み結果・全画像を対象に、同時3件ずつ順次テストする機能を追加した。
- 一括テストの進捗、結果別件数、停止操作を追加した。
- 表示できた画像にはプレビューを表示し、内容をユーザーが確認できるようにした。
- 表示テスト結果を作業状況とは独立して管理し、画像ID・結果・検査日時だけをプロジェクト別のローカルストレージへ保存するようにした。
- JSON切り替え時には進行中の画像読み込みを破棄し、以前の入力に対する結果が混入しないようにした。
- CSVへ表示テスト結果と検査日時を追加した。

## 2026-09-28 保存済み表示テスト結果の消去

- 現在のプロジェクトに保存された表示テスト結果を、確認画面の承認後にすべて消去して未判定へ戻せるようにした。
- 消去時は検査日時とセッション内のプレビューも破棄し、一括テストまたは個別テストの実行中は操作できないようにした。
