## 2026-09-27 表示テストの画像形式

- Gyazo画像の表示テストでPNGとJPGの両形式を確認するようにした。
- どちらか一方を読み込めた場合は「表示できた」、両方がエラーになった場合は「表示できない」、制限時間内に確定しない場合は「時間切れ」とするようにした。
- 表示できた形式を結果とともに保存し、プレビューの再表示に利用するようにした。

## 2026-09-27 表示テスト時のブラウザ

## 2026-09-27 表示テストの対応形式追加
