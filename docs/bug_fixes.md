# バグ修正

## 2026-09-28 JSON読み込み時の競合防止

- JSONファイルの読み込みごとに識別子を発行し、最新の読み込みだけを画面へ反映するようにした。
- 先に選択したファイルの読み込み完了やエラーが遅れても、後から選択したファイルの画面とメッセージを上書きしないようにした。

## 2026-09-28 CSVインジェクション対策

- CSVセルが`=`、`+`、`-`、`@`、タブ、改行で始まる場合、先頭にアポストロフィを付けて表計算ソフトによる数式解釈を防ぐようにした。
- 無害化した後に既存の引用符処理を行い、ページ名を含むCSVの全列へ同じ対策を適用した。
