# Cosense Gyazo 配信再開チェッカー

Cosense（旧Scrapbox）のプロジェクトエクスポートJSONからGyazo画像を抽出し、ブラウザで表示可否を確認する静的Webツールです。ビルドやサーバーは不要です。

## 使い方

1. `index.html` をブラウザで開きます。
2. CosenseのプロジェクトエクスポートJSONをドロップするか、ファイル選択から読み込みます。
3. 必要に応じて各画像の「表示をテスト」、または対象範囲を選んで一括テストを実行します。
4. プレビューと「Gyazoで開く」で画像を確認します。
5. 公開して問題ない画像は、Gyazo上でユーザー自身が「配信を再開する」を押します。

このツールはGyazo上の配信状態や配信再開作業の完了状態を管理せず、配信再開ボタンも自動操作しません。

## 表示テスト

「表示をテスト」は、`https://i.gyazo.com/{画像ID}` のPNG・JPG・GIF・MP4形式を読み込みます。静止画とGIFはブラウザの `Image` オブジェクト、MP4は自動再生しない `video` 要素で検査します。いずれかを読み込めれば「表示できた」、すべてでエラーが発生すれば「表示できない」、12秒以内に判定が確定しなければ「時間切れ」と記録します。再テストでは検査用クエリを付け、古いキャッシュの影響を抑えます。HTTPステータスは取得・表示しません。

表示テストには、シークレットブラウザ、またはGyazoとCosenseのどちらにもログインしていないブラウザを使用してください。

一括テストは「現在のページ」「検索・表示テスト結果の絞り込みに一致する全件」「抽出した全画像」から対象を選択できます。同時に3件ずつ処理し、途中で停止できます。JSONを切り替えると進行中の処理を破棄するため、古い結果が新しい一覧へ混ざりません。

「表示できない」は、配信停止を確定する結果ではありません。画像形式、URL、通信障害、アクセス制限、時間切れなどでも失敗します。「表示できた」場合も代替画像が返る可能性があるため、プレビューの内容を確認してください。表示テスト結果は検査時点の記録であり、配信状態や配信再開作業の完了を保証しません。

## 表示テスト結果の保存

表示テスト結果はブラウザのローカルストレージに、プロジェクト名ごとに保存します。保存するのは画像ID、判定、検査日時、表示できたファイル形式だけです。過去の結果は検査時点の記録であり、現在の表示可否を保証しません。JSON本文、画像データ、ファイル名、ページ名、行テキスト、抽出元URL、検索語は保存しません。

ブラウザのサイトデータを削除した場合や、別のブラウザ・端末を使った場合は結果を復元できません。

## CSV出力

「表示テスト結果をCSV出力」から、画像ID、確認用URL、表示テスト結果、検査日時、掲載元ページを出力できます。未判定は「未判定」と出力します。Excelで日本語が文字化けしにくいよう、UTF-8 BOM付きで生成します。

## 通信とプライバシー

JSONの読み込みと解析はブラウザ内で完結し、読み込んだ内容をこのツールから外部へ送信しません。次の場合には外部通信が発生します。

- ページ表示時: Bootstrap CDN、Google Analytics（通常のページ閲覧計測のみ）
- 表示テストとプレビュー表示時: `i.gyazo.com` への画像取得
- ユーザーがリンクを開いた時: Gyazo、Cosense、Rutile3のリンク先、フィードバックフォーム

Google Analyticsには、JSON本文、ページ名、行テキスト、ファイル名、GyazoのURL・画像ID、検索語、表示テスト結果を含むカスタムイベントを送信しません。新たなカスタム解析イベントも実装していません。

## 対応形式

最上位にプロジェクト名の `name` と `pages` 配列を持ち、各ページが `title` と `lines` を持つCosenseのエクスポートJSONに対応します。行は `text` を持つオブジェクト形式と文字列だけの簡略形式の両方を読み込めます。`gyazo.com` と `i.gyazo.com` のURLを32桁の画像IDで同一視します。
