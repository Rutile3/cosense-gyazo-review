# Cosense Gyazo 配信再開チェッカー

Cosense（旧Scrapbox）のプロジェクトエクスポートJSONからGyazo画像を抽出し、画像ごとの配信再開作業を管理する静的Webツールです。ビルドやサーバーは不要です。

## 使い方

1. `index.html` をブラウザで開きます。
2. CosenseのプロジェクトエクスポートJSONをドロップするか、ファイル選択から読み込みます。
3. 各項目の「Gyazoで開く」で画像を確認します。
4. 公開して問題ない画像は、Gyazo上でユーザー自身が「配信を再開する」を押します。
5. このツールに戻り、状況を「完了」に変更します。必要に応じて「保留」「対象外」も選べます。

このツールの「完了」はユーザーの自己申告による作業記録です。Gyazo上の配信状態を自動検証せず、配信再開ボタンも自動操作しません。

## 進捗の保存

進捗はブラウザのローカルストレージに、プロジェクト名ごとに保存します。保存するのはGyazo画像IDと「完了・保留・対象外」の状況だけです。JSON本文、ファイル名、ページ名、行テキスト、抽出元URL、検索語は保存しません。同じブラウザで同じプロジェクトのJSONを再読込すると進捗を復元します。

ブラウザのサイトデータを削除した場合や、別のブラウザ・端末を使った場合は進捗を復元できません。

## CSV出力

「作業状況をCSV出力」から、画像ID、確認用URL、状況、掲載元ページを出力できます。Excelで日本語が文字化けしにくいよう、UTF-8 BOM付きで生成します。

## 通信とプライバシー

JSONの読み込みと解析はブラウザ内で完結し、読み込んだ内容をこのツールから外部へ送信しません。次の場合には外部通信が発生します。

- ページ表示時: Bootstrap CDN、Google Analytics（通常のページ閲覧計測のみ）
- ユーザーがリンクを開いた時: Gyazo、Cosense、Rutile3のリンク先、フィードバックフォーム

Google Analyticsには、JSON本文、ページ名、行テキスト、ファイル名、GyazoのURL・画像ID、検索語、作業状況を含むカスタムイベントを送信しません。

## 対応形式

最上位にプロジェクト名の `name` と `pages` 配列を持ち、各ページが `title` と `lines` を持つCosenseのエクスポートJSONに対応します。行は `text` を持つオブジェクト形式と文字列だけの簡略形式の両方を読み込めます。`gyazo.com` と `i.gyazo.com` のURLを32桁の画像IDで同一視します。
